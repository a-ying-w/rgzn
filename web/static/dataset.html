color 与 segmented

跨域实验的两个域

segmented 版本把叶片从背景中抠出，保留病斑形态但去掉土壤、光照等背景信息。 主模型只在 color 上训练，直接用 segmented 测试会跌到 68.35%，说明背景线索对预测有实质贡献。

数据来源与引用

PlantVillage 数据集由 Pennsylvania State University 与 EPFL 等机构发布，包含多种作物的健康与病害叶片图像。 本项目使用其中的番茄子集，共六类叶片状态。原始图片版权归数据集发布方所有，本项目仅用于课程研究与教学演示。

引用：Hughes, D. P., & Salathé, M. (2015). An open access repository of images on plant health to enable the development of mobile disease diagnostics. arXiv:1511.08060.
