含方法、结果与讨论

E1 · 迁移学习有效性

核心

比较 ResNet-18 从零训练、ImageNet 微调、自建 CNN 与 MobileNetV3，回答预训练到底带来多少收益。

ResNet-18 从零 98.15% → 微调 99.57%（+1.42 pp）；E0 冻结主干仅 90.09%。
查看对比 →

E2 · 数据增强消融

消融

无增强、基础增强、强增强三档，各含从零与微调两臂，检验增强在小数据集上的边际收益。

从零：无增强 96.58%、基础 98.15%、强增强 96.44%；强增强并未带来额外收益。
查看图表 →

E3 · 鲁棒性实验

关键

亮度、旋转、模糊三类各五级扰动，量化实验室精度与真实拍摄条件之间的差距。

亮度 5 级：迁移 93.44% vs 从零 17.53%；模糊 5 级两者仅 44.55% / 57.45%。
查看曲线 →

E4 · 跨域实验

关键

训练用 color、测试换 segmented，检验模型是否依赖背景颜色；并用域内重训作为上界参照。

同域 99.57% → 跨域零样本 68.35%（−31.22 pp）；域内重训可回到 99.57%。
查看实验 →

E5 · 可解释性分析

分析

用 Grad-CAM 观察模型关注区域，判断它是否落在真实病斑上，与跨域实验的背景依赖相互印证。

热力图可直接对照原始叶片检查；实现位于 src/models/gradcam.py，不依赖第三方 CAM 库。

数据增强消融：测试集准确率

同一划分、同一评测

从零训练对增强更敏感（+1.57 pp），但强增强反而略低于基础增强；预训练模型对增强不敏感（−0.28 ~ −0.50 pp）。说明在数据量有限时，增强并非越多越好。

如何复现

命令来自 README

1. 构建前端数据（只读汇总）

python scripts/build_web_data.py

2. 启动推理与站点

python web/server.py

3. 重新训练主模型（可选）

python -m src.train --config configs/e1_resnet18_ft.yaml --seed 42

4. 重新生成图表（可选）

python scripts/make_figures.py

训练与评测只读写 runs/ 与 results/，前端展示只读这些产物，两者互不影响。
