MODEL OVERVIEW

模型概览

主模型采用 ImageNet 预训练的 ResNet-18 整体微调。选型不是"越大越好"，而是在精度、参数量与推理成本之间取平衡点。

主模型：ResNet-18 输入 224×224 6 类输出 权重已加载

ResNet-18 结构示意

ImageNet → 番茄六分类
输入224×224×3
Stem7×7 Conv /2
MaxPool
Layer 1–2BasicBlock ×4
64 / 128 通道
Layer 3–4BasicBlock ×4
256 / 512 通道
池化Global AvgPool
512 维
分类头FC 512→6
Softmax

残差连接缓解深层网络退化；整体微调时 backbone 与 head 使用分组学习率（1e-4 / 1e-3）。

为什么不是 MobileNetV3？ 在相同协议下，MobileNetV3-Small 的测试准确率与 ResNet-18 接近（99.57% vs 99.57%），参数量仅为 1.52M， 但其在强扰动下的稳定性并不优于 ResNet-18，且本项目部署在本地 CPU 也能接受的范围内。最终以 ResNet-18 作为主模型。
